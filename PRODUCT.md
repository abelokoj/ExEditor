# ExEditor

A native Windows/macOS/Linux editor replicating macOS TextEdit's rich/plain editing and compact interface. Repository: https://github.com/abelokoj/ExEditor.

User-selected: Rust + Native Shell (nsh) interface and native RichEditor, GitHub-only builds, local visual testing of downloaded artifacts. All feature source must be written before the first build/test. No external office suite. Rich font: Pretendard Std. Plain font: Maple Mono NF. Bundle only Regular/Italic/Bold/Bold Italic where genuine faces exist.

Visual authority: actual TextEdit screenshots under dev_notes/. Preserve this committed system, no independent concept generation. UI mode: Operate. Initial target is Windows x64 (the local test host); macOS execution is not claimed.
