ExEditor keyboard shortcuts (Windows)
=====================================

Help > Keyboard Shortcuts opens a searchable native command/keybinding panel.
This complete reference is also bundled as KEYBOARD_SHORTCUTS.txt.

These bindings apply in a document window. A command can be unavailable when
the document has no selection, no saved path, no matching text, or no suitable
rich-text context. Dialogs and search fields retain their own text-input keys.

Files and tabs
--------------
Ctrl+N                    New document tab
Ctrl+Shift+N              New document window
Ctrl+O                    Open files with the file picker
Ctrl+P                    Quick Open: search open and recent files
Ctrl+R                    Open the Recent Files menu
Ctrl+S                    Save
Ctrl+Shift+S              Save As
Ctrl+K S                  Save all documents
Ctrl+W / Ctrl+F4          Close the current document tab
Ctrl+Shift+W              Close the current window
Ctrl+K Ctrl+W             Close all documents
Ctrl+Shift+T              Reopen a closed saved file
Ctrl+Q                    Quit
Ctrl+Tab / Ctrl+PageDown   Next tab
Ctrl+Shift+Tab            Previous tab (also Ctrl+PageUp)
Ctrl+Shift+PageUp         Move the current tab left
Ctrl+Shift+PageDown       Move the current tab right
Ctrl+K P                  Copy the saved file's path
Ctrl+K R                  Reveal the saved file in Explorer
Ctrl+K Ctrl+P             Print
Ctrl+K Ctrl+Shift+P       Page Setup

Find and navigation
-------------------
Ctrl+F                    Find
Ctrl+H                    Replace
F3                        Find next
Shift+F3                  Find previous
Ctrl+E                    Use the selected text for Find
Ctrl+G                    Go to line
Ctrl+J                    Jump to the selection
Ctrl+Shift+\              Jump to the matching bracket
Ctrl+Up                   Scroll up one line
Ctrl+Down                 Scroll down one line
Alt+PageUp                Scroll up one page
Alt+PageDown              Scroll down one page

Native text navigation remains available: arrows, Home/End, PageUp/PageDown,
Ctrl+Left/Right for words, and Ctrl+Home/End for the document. Add Shift to
extend the selection. Backspace/Delete and Ctrl+Backspace/Delete stay native.

View and formatting
-------------------

Ctrl+Shift+R              Toggle the ruler
Ctrl+B                    Bold
Ctrl+I                    Italic
Ctrl+U                    Underline

Ctrl+Shift+C              Text colors
Ctrl+Shift+M              Switch rich/plain text format
Ctrl+Shift+.              Increase font size
Ctrl+Shift+,              Decrease font size
Ctrl+;                    Check spelling

Zoom also accepts Ctrl+Plus, Ctrl+Shift+=, Ctrl+Num+, and Ctrl+Shift+Num+.
The plus key always zooms. Ctrl+Num- also zooms out.
Font-size decrease also accepts Ctrl+Shift+- and Ctrl+Shift+Num-.
Use Ctrl+Shift+. / Ctrl+Shift+, for the font-size increase/decrease pair.

How chords work
---------------
Press Ctrl+K, then press the second combination within three seconds.
For Ctrl+K S, release Ctrl before pressing S: this saves all documents.
For Ctrl+K Ctrl+S, hold or press Ctrl again with S: this opens this reference.
Modifier presses/releases preserve a pending chord. Escape cancels it.
An unrecognized second key cancels the chord and is consumed once.
After the timeout, the next key works normally.
AltGr (Ctrl+Alt) always remains available for typing and cancels a pending chord.

VS Code compatibility and deliberate differences
------------------------------------------------
The supported editing bindings follow the Windows VS Code reference:
https://code.visualstudio.com/shortcuts/keyboard-shortcuts-windows.pdf

ExEditor retains Ctrl+B / Ctrl+I / Ctrl+U for rich-text bold/italic/underline.
Ctrl+Space opens the editor's word completion, rather than language-server
completion or parameter hints. Ctrl+T opens the font dialog, Ctrl+Shift+M
switches document format, and Ctrl+J jumps to the current selection.

Ctrl+P is Quick Open; Ctrl+O opens the file picker.
Ctrl+R opens recent files; the ruler uses Ctrl+Shift+R.
Print and Page Setup use the Ctrl+K chords above.
Ctrl+Shift+. / Ctrl+Shift+, change font size, while Ctrl+Plus changes zoom.

This is a native single-selection document editor. Multiple simultaneous
cursors, column selection, folding, symbol navigation/refactoring, language
server actions, editor groups, workspaces, project-wide search, source control,
debugging, extensions, and an integrated terminal are unavailable. Their
VS Code shortcuts are not assigned to placeholder commands.
