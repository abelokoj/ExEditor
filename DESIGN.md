# ExEditor interface

Authority: dev_notes/textedit-reference.png and textedit-settings-reference.png. Reproduce TextEdit's established controls. UI/UX Pro Max's focus guidance, Bencium's committed-system path, and Impeccable's Operate craft floor apply.

Light chrome #E7E7E7; toolbar #F0F0F0; paper #FFFFFF; ink #242424; borders #B8B8B8. Dark chrome #303030; toolbar #383838; ink #EEEEEE; borders #545454. White document paper remains in dark chrome.

Titlebar 31 logical pixels; app menu 24; toolbar 29; ruler 28. Controls 21 high, 3-pixel gaps, 4-pixel radii. Compact geometry follows TextEdit. Pretendard Std 12pt rich documents, Maple Mono NF 11pt plain documents. Fonts embedded privately, no system installation.

Native RichEdit provides caret, selection, IME, clipboard, history and accessible document semantics. GPUI Kit buttons/checkboxes/inputs provide keyboard controls and focus rings. Separate menu/panel windows appear above the native document surface.

Proof: source implementation only. No successful build, visual parity or human approval claimed. Differences recorded in dev_notes/known-differences.md.
