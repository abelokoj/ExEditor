# ExEditor paper-and-pencil variants

All three original PNG variants are retained here. Generation prompts remain local and are excluded from GitHub.

1. `variant-1-ex.png`: calligraphic Ex. User-selected default application icon.
2. `variant-2-exeditor.png`: calligraphic ExEditor. Preview; transparent perimeter needs cleanup.
3. `variant-3-exeditor-latex.png`: LaTeX-inspired ExEditor calligraphy.

The default PNG is copied to `assets/ExEditor.png`; the Windows multi-size resource is `assets/ExEditor.ico`. Original previews are unchanged. The resource is used by the executable, taskbar, installer, shortcuts, and optional document Open With registration. No system-wide user icon settings are changed.
